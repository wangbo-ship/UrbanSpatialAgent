# 接口文档（当前版本）

> 后端：FastAPI · 默认地址 `http://127.0.0.1:8000`  
> 前端开发时通过 Vite 代理访问 `/api/*`（等价于请求本机 8000）  
> 在线调试页（可选）：http://127.0.0.1:8000/docs  

说明：当前已提供静态数据读取，以及对话 / Agent / GIS 分析（`POST /api/chat`）。RAG、报告导出、流式输出仍属后续阶段。

---

## 通用说明

| 项 | 说明 |
|----|------|
| 协议 | HTTP |
| 前缀 | `/api` |
| 数据格式 | 除图层文件外，响应多为 JSON，编码 UTF-8 |
| 鉴权 | 无（一期未做登录） |
| 根路径 `/` | 无页面，返回 `{"detail":"Not Found"}` 属正常 |

---

## 接口列表

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查 |
| GET | `/api/config` | 地图/校区默认配置 |
| GET | `/api/demos` | Demo 剧本列表 |
| GET | `/api/models` | 可选模型列表（供前端切换） |
| POST | `/api/chat` | 空间问答（Agent + GIS） |
| GET | `/api/layers` | 图层名称列表 |
| GET | `/api/layers/{layer_name}` | 获取指定图层 GeoJSON |

---

## 1. 健康检查

- **URL**：`GET /api/health`
- **说明**：确认后端进程是否正常

**成功响应示例：**

```json
{
  "status": "ok",
  "app": "UrbanSpatialAgent"
}
```

---

## 2. 读取配置

- **URL**：`GET /api/config`
- **说明**：读取仓库 `data/config.json`
- **失败**：文件不存在时返回 `404`，`detail` 为 `config.json not found`

**成功响应字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `campus_name` | string | 校区/区域名称 |
| `campus_center` | number[2] | 中心点 `[经度, 纬度]` |
| `default_zoom` | number | 默认缩放级别 |
| `default_radius_m` | number | 默认半径（米） |
| `map_attribution` | string | 底图版权说明 |

**成功响应示例：**

```json
{
  "campus_name": "中国地质大学（武汉）未来城校区",
  "campus_center": [114.615, 30.458],
  "default_zoom": 15,
  "default_radius_m": 1000,
  "map_attribution": "© OpenStreetMap"
}
```

---

## 3. 读取 Demo 剧本

- **URL**：`GET /api/demos`
- **说明**：读取仓库 `data/demos.json`
- **失败**：文件不存在时返回 `404`

**成功响应字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `demos` | array | 剧本数组 |
| `demos[].id` | string | 剧本编号 |
| `demos[].title` | string | 标题 |
| `demos[].question` | string | 预设问题文案 |

**成功响应示例：**

```json
{
  "demos": [
    {
      "id": "D1",
      "title": "覆盖速查",
      "question": "未来城校区周边 500 米内有多少所学校和医院？"
    }
  ]
}
```

---

## 4. 图层列表

- **URL**：`GET /api/layers`
- **说明**：列出 `data/layers/` 下所有 `.geojson` 的文件名（不含扩展名）

**成功响应示例：**

```json
{
  "layers": ["events", "hospitals", "parks", "schools"]
}
```

若目录不存在，返回 `{"layers": []}`。

---

## 5. 获取单个图层

- **URL**：`GET /api/layers/{layer_name}`
- **路径参数**：

| 参数 | 说明 | 示例 |
|------|------|------|
| `layer_name` | 图层名（对应 `data/layers/{name}.geojson`） | `schools` |

- **说明**：返回 GeoJSON 文件内容，`Content-Type` 为 `application/geo+json`
- **失败**：图层不存在时返回 `404`

**成功时**：响应体为标准 GeoJSON `FeatureCollection`（点要素等），例如学校图层中的 `geometry.coordinates` 为 `[经度, 纬度]`。

**调用示例：**

```text
GET http://127.0.0.1:8000/api/layers/schools
GET http://127.0.0.1:8000/api/layers/hospitals
GET http://127.0.0.1:8000/api/layers/parks
GET http://127.0.0.1:8000/api/layers/events
```

## 与前端的关系

预览与对话页加载时大致会请求：

1. `/api/config` — 定中心与校区名  
2. `/api/layers` — 知道有哪些图层  
3. `/api/layers/{name}` — 逐个加载并画到 Leaflet  
4. `/api/demos` — Demo 快捷问题  
5. `/api/models` — 模型下拉框  
6. `POST /api/chat` — 发送问题，拿答复、工具轨迹、`map_actions` 落图  

前端开发地址一般为 `http://localhost:5173`，其中 `/api` 由 Vite 代理到 `8000`。

---

## 6. 模型列表

- **URL**：`GET /api/models`
- **说明**：读取 `data/models.json`，并标记云端模型是否已配置 API Key

**成功响应示例：**

```json
{
  "default_model_id": "ollama-qwen",
  "models": [
    {
      "id": "ollama-qwen",
      "name": "Qwen2.5（Ollama 本地·免费）",
      "provider": "ollama",
      "free": true,
      "ready": true,
      "needs_key": false,
      "note": "需本机安装 Ollama..."
    }
  ]
}
```

## 7. 空间问答（Agent）

- **URL**：`POST /api/chat`
- **Body（JSON）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `question` | string | 用户问题（必填） |
| `model_id` | string | 可选，对应 `/api/models` 的 id |
| `force_rule` | bool | 可选，强制规则回退（调试） |

**成功响应字段：**

| 字段 | 说明 |
|------|------|
| `answer` | 助手文字答复 |
| `trace` | 工具调用轨迹（工具名、参数、结果摘要） |
| `map_actions` | 前端地图指令（setView / addGeoJSON） |
| `model_id` | 实际使用的模型或 `rule-fallback` |
| `mode` | `llm` 或 `rule` |

大模型不可用时会自动规则回退，仍可用 Demo 演示 GIS。

**请求示例：**

```json
{
  "question": "未来城校区周边 500 米内有多少所学校和医院？",
  "model_id": "ollama-qwen"
}
```
