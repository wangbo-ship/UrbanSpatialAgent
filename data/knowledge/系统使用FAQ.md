# 城市治理空间问答助手 · 使用说明（样例）

## 系统能做什么

- 自然语言提问，调用 GIS 工具做缓冲、相交、计数、距离判定。
- 在 Leaflet 地图上落缓冲圈与高亮点。
- 检索本地知识库（规范摘要、FAQ），辅助政策口径类回答。
- 将一次分析结果导出为研判报告（Markdown）。

## 默认研究区

中国地质大学（武汉）未来城校区附近样例数据。

## 可用图层

| 图层名 | 含义 |
|--------|------|
| schools | 学校 |
| hospitals | 医院 |
| parks | 公园 |
| events | 投诉点 / 拟建点等事件 |

## 常见问题

**Q：没有 API Key 能演示吗？**  
A：可以。系统会规则回退，点击 D1/D2/D3 仍可跑通 GIS；知识库检索不依赖大模型。

**Q：数字会不会是模型编的？**  
A：不会。坐标、数量、距离由后端 Shapely/PyProj 计算，模型只负责选工具与组织语言。

**Q：如何导出报告？**  
A：完成一次问答后，点击「导出研判报告」，下载 Markdown 文件。
